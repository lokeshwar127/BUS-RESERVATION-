# BHARAT BUS — Golden Hour All-India Reservations

An interactive bus ticket reservation web application featuring 3D coach visualization with Three.js, dynamic seat booking, interactive seat maps, and modern UI built with Tailwind CSS and GSAP animations.

## Features
- **3D Bus Coach View**: Interactive Three.js coach rendering with camera controls.
- **Interactive Seat Selection**: Lower and upper deck seat maps with real-time price calculation.
- **Boarding & Dropping Points**: Filter and select pickup and drop locations across major Indian routes.
- **Passenger Details & Booking Flow**: Complete checkout flow with instant booking confirmation.

## Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- [Tailwind CSS](https://tailwindcss.com/)
- [Three.js](https://threejs.org/)
- [GSAP](https://greensock.com/gsap/)

## Running Locally
Simply open `index.html` in your favorite web browser, or use a local development server (such as Live Server in VS Code):
```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```
